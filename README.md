# VOXSHIFT

Complete six-page frontend, using the provided UI reference and logo.

## Start

```bash
cd frontend
npm install
npm run dev
```

See `frontend/README.md` for the full implementation, testing, and limitations.

This is Phase 1: frontend. Local audio effects work; reference-based AI conversion is clearly unavailable until a real backend and pretrained inference model are connected. No database or permanent user-audio storage is implemented.
